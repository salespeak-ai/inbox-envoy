# Contributing

Focus on safe, portable instructions for existing personal agents. Propose changes with synthetic fixtures and host capability tests. Never share private mail or credentials. Run `python -m unittest discover -s tests -p 'test_*.py'` and `python demo/smoke_local.py` before submitting changes.

Report sensitive vulnerabilities privately through GitHub private vulnerability reporting (Security tab, "Report a vulnerability"). Do not attach exploit payloads containing any real user data to public issues. Changes to scheduling, research permissions, archiving, message sends or live agent connections must preserve opt-in and fail-open behaviors.
